# SOBHAN VPN — رابط اولیه

این پوشه شامل نسخه اولیه و واکنش‌گرای رابط وب SOBHAN VPN است.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای پیش‌نمایش می‌توان از افزونه Live Server در VS Code نیز استفاده کرد.

## وضعیت فعلی
- رابط وب فارسی و راست‌چین: آماده
- داشبورد و کنترل نمایشی: آماده
- موقعیت برنامه‌ریزی‌شده: هلند
- پروتکل برنامه‌ریزی‌شده: WireGuard
- سرور واقعی: هنوز تهیه/راه‌اندازی نشده
- اپلیکیشن اندروید: هنوز ساخته نشده
- اتصال واقعی VPN: پیاده‌سازی نشده

## گام‌های بعدی برای سرویس واقعی
1. تهیه VPS هلند با کمک سرپرست/بزرگسال.
2. نصب و پیکربندی امن WireGuard روی سرور.
3. طراحی API امن برای صدور و لغو پیکربندی‌های کاربر؛ کلید خصوصی کاربر نباید به سرور یا وب‌سایت افشا شود.
4. ساخت اپلیکیشن اندروید با مجوز رسمی VPN و اتصال به تونل WireGuard.
5. افزودن احراز هویت، محدودسازی دسترسی، ثبت رخدادهای حداقلی و مستندات حریم خصوصی.

**مهم:** دکمه اتصال در این نسخه صرفاً نمایشی است و تونل شبکه ایجاد نمی‌کند.
